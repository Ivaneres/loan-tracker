How it works

PrimaryThree peers only: Home (dashboard), Spending (the four money pages), Loans. The active group gets the dark pill.
ContextThe sub-row mirrors Today / Plan / Goals already used on the Daily page, so it reads as familiar, not new.
ActionSearch stops being a destination and becomes one segment here — it's a verb you run on your transactions, not a page you live in.
SignalReconcile carries a small count badge (2) so the recurring monthly task is discoverable from anywhere in the app.
RuleDirect links (/spending/daily, /spending/reconcile?month=…, search deep-links) still work — the sub-row just reflects whatever section is active.
