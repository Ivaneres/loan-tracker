What it fixes / costs

  • Smallest possible change — five of six labels stay exactly where users expect.
  • Menu can be grouped with headers, so Reconcile/Search/Loans get real context.
  • Absorbs future items without touching the primary row.
  • Three destinations are hidden one click deep — discovery drops.
  • Which items are “most used” is a guess; it will drift.
  • Reconcile — a monthly must-do — is easy to forget when it's only a badge in a menu.
Best forTeams that want the change shipped this week with near-zero user retraining.
